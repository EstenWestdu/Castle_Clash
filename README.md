## 游戏简介
《城堡大作战》是一款基于Python和Pygame Zero开发的塔防策略游戏。玩家需要在地图上部署三种不同类型的炮塔，抵御不断来袭的怪物军团，保护城堡免受破坏。

## 游戏特色
🏰 三种独特炮塔 - 每种炮塔都有不同的攻击方式和价格

🎯 策略性布局 - 合理规划炮塔位置，最大化防御效果

⚔️ 多样化的敌人 - 多种怪物类型，各有不同的特性和能力

📈 经济系统 - 管理经济建造更强大的炮塔，应对更强大的敌人

🎮 简单易上手 - 直观的操作界面，适合所有年龄段的玩家

## 游戏玩法
### 炮塔类型
#### *枪弹塔* 🏹

基础攻击力中等

攻击速度较快

价格低廉

#### *减速塔* 🔮

减速效果

攻速较低

#### *加农炮* 💣

高伤害

攻击速度较慢

有溅射伤害

## 游戏目标
在怪物到达城堡前将其消灭

合理管理资源，建造和升级炮塔

生存尽可能多的波次，获得高分
